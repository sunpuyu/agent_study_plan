# 笔记
1、os.system vs subprocess.run
os.system：老旧、简单，只能拿到命令退出码，拿不到标准输出 / 错误文本，不推荐新项目。
subprocess.run：Python3.5 + 推荐的现代 API，功能完整，可以捕获 stdout/stderr、控制输入、超时，是 Agent 执行 shell 命令首选。
